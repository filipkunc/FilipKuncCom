# About

I'm Filip Kunc. This site is where I keep notes, projects, and experiments, mostly around graphics, systems programming, and the web. I like taking ideas apart, getting them running in the browser, and writing up what I learned. I started by porting my old work and added posts as I went.

I'll be honest, I used Claude Code heavily for development and writing,
but the direction and especially the testing approaches are mine.

## Projects

- [MeshMaker](/meshmaker) — WebGL2 + WASM port of a 3D mesh editor for macOS | Windows | Linux.
- [Space Warrior](/space-warrior) — Platformer in DirectX and C++ ported to web (2002-2003).
- [Gentis](/gentis) — OpenGL 3D third-person shooter (2004-2005).
